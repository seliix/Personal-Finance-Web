# ClearPath Money

A Streamlit website focused on helping people improve their personal finances with:

- A monthly budget snapshot
- Spending mix and 50/30/20 guidance
- Debt payoff coaching
- Emergency fund planning
- Savings goal tracking
- Simple educational content for better money habits

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## What the site does

Enter a person's monthly income, expenses, debt payments, and savings goals in the sidebar. The app then generates:

- A personalized dashboard
- Budget category charts
- Practical next-step recommendations
- Debt payoff guidance
- Emergency fund progress
- A savings timeline forecast

## Notes

- The app is built with Streamlit, Plotly, and pandas.
- No external data source is required for the current experience.
